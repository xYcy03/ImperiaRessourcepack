# Imperia SMP Resource Pack

Minecraft Java 26.1 resource pack for the Imperia SMP TAB header and rank glyphs.

## Glyph mapping

- `U+E000`: Imperia TAB banner
- `U+E001`–`U+E00E`: owner, manager, developer, admin, moderator, supporter, builder, helfer, peria, monarch, titan, apex, guardian, default

The bitmap glyphs use the resource pack's `minecraft:default` font and retain the vanilla font providers as fallbacks.
