# Imperia SMP Resource Pack

Minecraft Java 26.1 resource pack for the Imperia TAB banner, custom fantasy rank emblems, and scoreboard icons.

## Glyph mapping

- `U+E000`, `U+E00F`, `U+E010`: three adjacent bitmap cells forming the transparent Imperia banner
- `U+E001`–`U+E00E`: Owner, Manager, Developer, Admin, Moderator, Supporter, Builder, Helfer, Peria, Monarch, Titan, Apex, Guardian, Spieler emblems
- `U+E011`: Geld icon; `U+E012`: Coins icon; `U+E013`: Piñata icon

The font definition includes Minecraft's vanilla fallback providers. The resource pack remains optional on the server.
